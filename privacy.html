Privacy policy

Shuki Calendar Sync · last updated October 1, 2026

Who uses it

Shuki Calendar Sync is a personal tool. Its only user is its author, signed in with the author's own Google account.

What it accesses

  • To-do notes on the author's own computer.
  • In Google Calendar, only the "Shuki To-Dos" calendar it created itself. Google's permission for this tool (calendar.app.created) does not allow it to see or change any other calendar.

What it does with that data

It creates, updates and deletes events in the "Shuki To-Dos" calendar so they match the to-dos. That is all it does with the data.

What it keeps

A small file on the author's computer records which event belongs to which to-do, along with the Google sign-in that lets the nightly run work. Nothing is stored anywhere else.

Sharing

No data is sold, shared, or sent anywhere except the author's own Google Calendar. There are no analytics, ads, or third parties.

Removing access

Access can be withdrawn at any time from the Google account's "Third-party apps and services" page. Deleting the "Shuki To-Dos" calendar removes every event the tool made.
